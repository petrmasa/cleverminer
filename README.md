# CleverMiner

Beyond apriori: enhanced association rule mining (eARM) implementing the
GUHA procedures (4ft-Miner, CF-Miner, SD4ft-Miner, UIC-Miner) over
categorical data — interpretable by construction.

**This repo is WIP (work in progress)** — see [CONTRIBUTING.md](CONTRIBUTING.md)
before opening a pull request.

- **Install**: `pip install cleverminer`
- **Documentation and examples**: https://www.cleverminer.org
