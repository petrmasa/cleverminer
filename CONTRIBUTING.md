# Contributing

CleverMiner is currently going through a large internal restructuring
(large refactoring of the mining engine and other changes). Because of that, the codebase is not in a
stable shape for outside contributions right now.

**If you'd like to contribute, please contact the author first**
(code@cleverminer.org) before opening a pull request, so we can figure out
whether it fits with the restructuring in progress.

Bug reports and questions are still welcome via Issues in this repo.
